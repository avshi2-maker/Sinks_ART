### Architecture principle Avshi set: "split into a million pieces for smart future changes."
Jobs will scale (multi-sink + addons + ZERO doors module). Everything is split by concern so a
future change touches ONE small file, never a monolith:
- `src/lib/po/workOrderTypes.ts` — shared types. LineKind = 'sink'|'addon'|'door'. WorkOrderLine
  carries material cost per line. **Doors slot reserved**: door lines fill doorId/doorSvg; when the
  ZERO doors module is ready, create a door line by reading a door record — work order doesn't need
  to know how doors are designed.
- `src/lib/po/sketchSpecToDims.ts` — maps sketch mm-keys → materialCalc cm-keys. rim defaults 3.5cm
  (verified Goldman). ONLY file to change if the sketch builder adds/renames a field.
- `src/lib/po/workOrderFinance.ts` — THE MONEY MODEL (the file that will change most). Sums line
  items → totalMaterial, alesProfit, profitShare. buildFinance (freeze) / previewFinance (live) / ils().
- `src/lib/po/createWorkOrderFromSketch.ts` — now takes { sketchId, orderAmountIls, commissionIls,
  factors? }, runs the calc, freezes a WorkOrderFinance snapshot into production_orders.cut_list (jsonb).
- `src/components/demos/AlesFinalizePanel.tsx` — Ferrari finalize panel on the sketch card. Opens →
  fetches material settings once → live cut-list preview (sheets/m²/leftover/material ₪) → order amount
  + commission inputs → live Ales-profit line → create → route to /po/[id]/ales.
- `src/components/demos/DemoCard.tsx` — 🔧 אלס button now toggles the finalize panel (was: instant create).
