## ⚠️ SCAR-TISSUE LESSONS (hard-won — apply from the start)
1. "I don't see my change" → FIRST ask which URL (localhost vs live) and which PAGE the feature lives on.
2. A sketch in /sketch is browser-only until שמור לגלריה is clicked — no autosave.
3. Deliver files as DOWNLOADS only; verify staged files with git status before commit.
4. Type-defining file must land on disk before/with its consumer (build error "Property X does not exist").
5. Backups NEVER in src/ — next build type-checks them and fails. Use /_backups/.
6. Do NOT run `npm run build` while the T1 dev server runs — corrupts shared .next → pages 404 despite
   existing. Fix: Ctrl+C dev server, `npm run dev` again.
7. **NEW: EMOJI ANCHORS FAIL in console edits.** Emoji (📐 🏷️ ⚙️) mutate in copy-paste → anchor count 0 →
   abort. ROBUST PATTERN: anchor on plain-ASCII text (href strings, function names), carry any Hebrew/emoji
   payload as BASE64 decoded inside PowerShell, insert by LINE INDEX. Used successfully for the nav links.
8. Hebrew PDFs: never cairosvg; wkhtmltopdf with dir="rtl", verify by rasterizing back.
9. PowerShell .Replace() on CRLF files can silently miss — always count matches first, abort if not exactly 1.
