## 🏆 SHIPPED THIS SESSION: the 3-page "Ferrari" Ales work-order document (LIVE, pushed)

The full pipeline now works end-to-end: sketch → pricing engine → work order → transparent 3-page doc.

### Flow
1. Sketch card → 🧮 תמחור → /sketch-to-offer?sketch=<id> (pricing engine, built last session).
2. Engine → 🔧 צור הוראת עבודה לאלס → freezes the FULL PricingResult + cutList + days into
   production_orders.cut_list (jsonb) as an AlesWorkOrderSnapshot (version:2) → routes to /po/[id]/ales.
3. /po/[id]/ales renders the 3-page document from that frozen snapshot (no recompute — what you saw is what's saved).

### The 3 pages (all in src/components/po/ales/)
- AlesHeroPage.tsx — PAGE 1 BOOM. Ales's total is THE giant number (e.g. ₪7,000), "שכר X + בונוס Y" under it,
  full transparent job breakdown (order, material, Avshi 15% commission, premium split — all OPEN), and a
  "גלול לעמוד 2-3" instruction (Avshi's rule: don't load heavy data on Ales in the sun; give the number + point to detail).
- AlesSketchPage.tsx — PAGE 2. Standalone print-ready production sketch (the frozen sketchSvg).
- AlesCostPage.tsx — PAGE 3. Full A-Z: 8-panel cut list + labor/overhead/consumables + true cost + offer math
  + premium split + both bottom-line totals (Ales + Marble Art, open).
- AlesDocument.tsx — container, stacks the 3 with @media print page-breaks (each = own A4), print button,
  graceful fallback for OLD pre-engine POs (no v2 snapshot → "create a new work order" message).
